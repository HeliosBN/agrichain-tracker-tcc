## 📋 Funcionalidades por Role:

- **Produtor:** Registrar produtos, rastrear produção
- **Distribuidor:** Receber produtos, gerenciar distribuição
- **Varejista:** Gerenciar estoque, vender produtos
- **Consumidor:** Rastrear produtos, verificar origem

## 🛠️ Como Usar:
1. Acesse o sistema em `http://localhost:5173`
2. Clique em "Login"
3. Use qualquer das credenciais acima
4. Teste as funcionalidades específicas de cada role
